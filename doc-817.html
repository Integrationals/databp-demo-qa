3. Concept

A page sends the conversation, with an access code, to a function on AWS Lambda. The function gives Claude Morgan's instructions, the current catalogue of metrics and dimensions, and three tools: list the metrics, get a metric's dimensions, and query metrics. Each tool calls dbt's hosted Semantic Layer in Production, the same service Hex and dbt's MCP read. The answer streams back to the page as it is written, and the page shows, under the final answer, each query that produced a figure. A reply that states a figure without a query is not shown.

6.5 Worked examples

Bin asks: "Why is subscriber 43 unbilled in October?"
