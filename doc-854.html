2. Logic areas

LA-1 The code and the hkey (each staging model)

Dimension: the model, 12 of them; each known row gives one code and one hkey. Brute force 12; no collapse, since each model has its own issuer, table and natural id. Design D-1, D-2.

LA-2 The hdiff (each staging model)

Dimensions: an attribute that matters changes (yes or no), the deletion flag flips (yes or no), only the load time changes (yes or no): 8 per model, 96 in all. Collapse: any change to an attribute or the deletion flag gives a different hdiff whatever the load time does, and no change or a load time alone gives the same one, so three paths per model show every outcome: 36. Design D-1, D-7.

LA-3 Silver's keys from codes (each silver model)

Dimension: the key, 11 names across 7 models, each made with generate_surrogate_key over its code. Brute force 11; no collapse. Each value must equal today's. Design D-4, D-5.

LA-4 The hdiff carried into silver (each silver model)

Dimension: the model, 7 of them, each replacing change_hash with its staging row's hdiff. Brute force 7; no collapse. Design D-7.
